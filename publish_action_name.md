# 🛠️ Which Action to Run for Publishing

There is one GitHub Actions workflow available for publishing:

### **`Publish Extension`**
- Defined in [publish.yml](file:///d:/KeshavSoftRepos/6aug-1/vs-code-ext-from-any-js/.github/workflows/publish.yml).
- Packages and publishes the extension directly to the VS Code Marketplace.
- Triggered manually via the GitHub Actions UI.
